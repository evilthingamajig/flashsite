# Build

This site is static HTML + shared CSS, but its <head> blocks are generated.

Re-run after editing `/css/*`, `site.js`, `js/*.js`, or adding/replacing images:

```
cd tools && npm ci && node build.mjs
```

The build is idempotent. It rewrites each page in place:

- `<!--ff:css <comma-list>--><style>…</style><!--/ff:css-->` in each page's <head> — inlined, PurgeCSS-cleaned, minified CSS generated from the source files in `/css` (the files listed in the marker, in order). `/css` remains the source of truth; edit there, then rebuild.
- Minified hashed JS at `/js/site.<hash>.js`, `/js/script.<hash>.js`, `/js/ff-map.<hash>.js` — references rewritten automatically. Sources stay at `/site.js` and `/js/*.js`.
- `<img>` tags get `srcset`/`sizes`/intrinsic dims from `/images/opt/` variants generated by `tools/imgopt.py` (WebP, q78). Original files are untouched.
- Font faces + metric fallbacks are prepended to the inlined CSS; hashed woff2 files live in `/fonts/` (regenerate with `tools/fonts.py`, needs Python 3 + fontTools + brotli (see `tools/requirements.txt`)).

Generated/measured inputs in `tools/`: `img-metrics.json` (rendered img boxes, from `tools/metrics.py`), `img-variants.json`, `lcp.json` (from `tools/lcp.py`). Regenerate them if image layout changes substantially.
